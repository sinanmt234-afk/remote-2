# Aether Remote
Oru APK: TV/projector-il "TV" mode, phone-il "Phone" mode.
1. GitHub-il puthiya repo undaakki ee folder-ile ellaa files-um upload cheyyuka (.github folder ulppede).
2. Actions tab > "Build APK" > Run workflow > artifact "aether-remote-apk" download.
3. Same APK TV stick-ilum projector-ilum phone-ilum install cheyyuka.
4. TV-yil: mode "TV" > Open Accessibility settings > Aether Remote ON. 4-digit PIN kaanum.
5. Phone-il: mode "Phone" > TV select > PIN adikkuka > remote ready.
